# 名鉴AI · 东方姓名文化取名工具

按出生时间与诗词典故取名的工具。填姓氏与出生时间，输出候选名字、典籍出处、  
四维评分（五行 / 音律 / 寓意 / 五格），可导出 HTML / Markdown / CSV / JSON。

**在线使用 → [www.mingli.xin](https://www.mingli.xin/)**

> 这个仓库只放项目介绍，代码不开源。用途是给项目一个公开的说明页。

---

## 它解决什么问题

取名工具大多只给一个名字，不解释为什么。这个工具每个名字都给出：

- **出处** —— 出自《诗经》《楚辞》《论语》《声律启蒙》哪一句，可核对
- **四维分数** —— 五行契合、音律、寓意、五格，各自打分而不是一个总分
- **评分依据** —— 为什么这个字得这个分

## 技术要点

- 历法层只用 [`lunar-python`](https://github.com/6tail/lunar-python) 一个依赖，  
  它自身零第三方依赖
- Web 服务用 Python 标准库 `http.server`，没有 Flask / FastAPI
- 排盘自带反查自检：用 `Solar.fromBaZi()` 由四柱反推公历时刻，验证节气与干支换算自洽
- 真太阳时校正、日主旺衰判定、五格与音律评分由项目自己实现

## 说明

工具输出基于公开通行的历法换算、字库与评分口径，属于文化研究与娱乐参考，  
不构成任何人生决策依据。命理与五格姓名学在学界存在争议，不同流派结论可能相左。
